# Ahmed Rashad — Portfolio

A bilingual personal portfolio focused on SEO, software development, and game development.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Getting started
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current milestone
- Responsive bilingual landing page (English / Arabic)
- SEO-first positioning with development and game-development sections
- Project showcase placeholders for Zekry, Shaghaf, and War of the Ages
- Accessible motion preferences and a dark visual system

## Next milestones
